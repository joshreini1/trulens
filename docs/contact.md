# Contact

TruLens is an open source project maintained by [Snowflake's AI Observability
team](https://github.com/truera/trulens/blob/main/GOVERNANCE.md). The best way to reach
the maintainers and community depends on what you need.

## Community discussion

Join the TruLens category in the Snowflake community forum to ask questions, share how
you use TruLens, and hear about releases:

- [TruLens community forum](https://snowflake.discourse.group/c/ai-research-and-development-community/trulens/97)

## Bugs and feature requests

Open a GitHub issue for a bug report, and a GitHub discussion for a feature request or a
"How do I…" question:

- [Report a bug](https://github.com/truera/trulens/issues/new)
- [Feature requests and discussions](https://github.com/truera/trulens/discussions)

## Contributing

If you want to contribute code, docs, or notebooks, start with the
[contributing guide](/contributing/development/) and the
[governance model](https://github.com/truera/trulens/blob/main/GOVERNANCE.md).

## Source

The code lives in the [truera/trulens](https://github.com/truera/trulens) repository on
GitHub, and the documentation you are reading now is built from the `docs/` directory of
that same repository.
